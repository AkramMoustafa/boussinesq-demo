Neural Operator · Fluid Dynamics

Boussinesq Vorticity Predictor

A Fourier Neural Operator trained on 2D Boussinesq convection — maps initial vorticity & temperature to the vorticity field at t = 100 in milliseconds. The amplitude ε is a user-controlled input.

FNO  4 layers
128×128 grid
multi-ε: 0.021 – 0.476
H2-normalized ICs
ν = 1  |  T = 100

Live Demo — powered by Hugging Face ZeroGPU

Amplitude ε

How It Works
1

Choose ε & generate ICs

Pick the amplitude ε. Gaussian Random Fields are drawn and normalized so that ‖u₀‖_H² = ‖θ₀‖_H² = ε/2.

2

Run the FNO

The operator takes (ω₀, θ₀, ε) and returns the vorticity field at t = 100 in milliseconds.

3

Visualize

All three fields displayed side by side with symmetric per-panel colormaps.

4

Download

Export the raw NumPy arrays as an .npz file for further analysis.
